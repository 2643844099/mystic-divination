# 🌙 星月占卜馆

一个沉浸式占卜网页程序：塔罗牌阵、星座运势、星座配对、每日一签、月相历法与许愿池。

## 运行方式

无需安装任何依赖，**直接双击打开 `index.html` 即可**（推荐 Chrome / Edge 浏览器）。

`index.html` 是**完全自包含的单文件版本**（CSS 与全部 JS 已内联），拷贝到任何地方都能独立运行。

> 提示：页面引用了 Google Fonts 字体（离线时自动回退到系统衬线字体，不影响功能）；
> 声音为 Web Audio 实时合成的风铃音效，默认开启，可在右上角 🔊 一键静音。

## 开发维护

源码按模块拆分在 `css/` 与 `js/` 目录中，修改源码后运行以下命令重新生成自包含版本：

```
node build-inline.js
```

> 注意：构建脚本用「函数替换」内联 JS（字符串替换会把 JS 中的 `$$` 误当作 `$` 转义），
> 且脚本是幂等的——对已内联的 index.html 重复执行也会正确更新。

## 功能一览

| 模块 | 说明 |
| --- | --- |
| 🔮 塔罗牌阵 | 78 张完整塔罗（22 大阿卡纳 + 56 小阿卡纳），**全部为手绘风格 SVG 牌面**（线稿徽章 + 笔触抖动滤镜 + 羊皮纸颗粒质感），支持单张指引 / 三张牌阵、3D 翻牌、正逆位解读与综合启示 |
| ✨ 星座运势 | 十二星座完整资料 + 每日运势（五星评级、幸运色、幸运数字、幸运星座、开运提示） |
| 💞 星座配对 | 缘分指数 + 激情/沟通/长久/浪漫四项维度分析、元素组合解读 |
| 🌌 出生星盘 | 输入出生日期/时间/城市，推算太阳、月亮、水星、金星、火星、木星、土星的落座 + 上升/中天，生成可交互星盘轮与元素能量解读 |
| 🎋 每日一签 | 24 支古签（上上签 → 下下签），竖排签诗 + 解签 |
| 🌙 月相历法 | 实时月相（SVG 月相图）、亮度、月龄、宜忌、满月/新月倒计时 |
| 🌠 许愿池 | 心愿放飞流星动画，本地持久保存 |

> 星盘采用简化天文算法（太阳含中心差，行星为平均黄经，娱乐级精度），上升/中天按等宫制计算。

## 沉浸感设计

- 入场仪式：推门进入占卜馆（门扉开合 + 烛光闪烁）
- 动态星空背景：闪烁星辰、缓缓漂移的星云、随机划过夜空的流星
- 鼠标星尘拖尾（触屏设备自动关闭）
- Web Audio 合成风铃声效：洗牌、翻牌、抽签、配对均有对应音色
- 每日签语、今日宜忌、星座寄语随日期变化

## 项目结构

```
├── css/

└── js/
    ├── data-tarot.js   # 78 张塔罗牌数据（牌义/关键词/正逆位）
    ├── data-zodiac.js  # 星座数据、运势文案库、配对规则
    ├── data-lots.js    # 24 支灵签数据
    └── app.js          # 全部交互逻辑（星空/声音/塔罗/配对/月相/许愿…）
```
